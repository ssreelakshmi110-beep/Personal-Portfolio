Personal Portfolio Website
About the Project
This is a responsive personal portfolio website created using HTML, CSS, and JavaScript. It showcases personal information, educational qualifications, technical skills, projects, interests, and contact details.
The website features a modern purple-and-white theme, smooth scrolling, animations, and a mobile-friendly layout.
Features
Home Section: Introduction and portfolio overview.
About Section: Personal introduction and educational details.
Skills Section: Displays programming and technical skills.
Projects Section: Showcases projects and programming practice.
Interests Section: Displays personal and technical interests.
Contact Section: Provides email and GitHub contact information.
Responsive Design: Supports desktop, tablet, and mobile devices.
Smooth Scrolling: Easy navigation between sections.
Mobile Navigation: Responsive menu for smaller screens.
Scroll Animations: Sections appear smoothly while scrolling.
Dynamic Copyright Year: Automatically updates the year.

Installation and Setup
Download or clone the project repository.
Open the project folder in Visual Studio Code.
Locate and open index.html.
(Optional) Install the Live Server extension in VS Code.
Right-click index.html and select Open with Live Server.
You can also double-click index.html to open it directly in a web browser.
Customization
Edit index.html to:
Change the name and personal introduction.
Update educational qualifications.
Add or remove technical skills.
Add new projects.
Update the email and GitHub details.
Modify colours, fonts, and layout using CSS.
Important: Replace the sample email address (your.email@example.com) and GitHub address (github.com/your-username) with the correct details.
